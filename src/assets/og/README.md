Fonts used only to render the social share image (`src/app/opengraph-image.tsx`).
The image renderer needs static TTF files, so these can't come from next/font.

- `Rubik-Black.ttf`: Rubik 900, from Google Fonts. SIL Open Font License 1.1.
- `EncodeSans-SemiBold.ttf`: Encode Sans 600, from the CBS brand assets. SIL Open
  Font License 1.1 (`OFL-EncodeSans.txt`).
